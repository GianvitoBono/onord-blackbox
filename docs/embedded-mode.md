# Embedded mode (future research)

Keep logger independent from appliance controls. Before modifying a device, verify exact OnePlus Nord model, hardware and firmware; prepare matching stock image, recovery path and data backup. Do not use Nord 2 procedures until model is confirmed.

Possible research: bootloader unlock implications; Magisk and patched boot image; vendor-supported boot-on-charger behavior or init trigger; privileged/system-app deployment; LineageOS/AOSP support; root shutdown after trip close and sync; charge limit around 60–70% using supported charging controls. Each path risks data loss, boot failure, warranty/security changes, or unsupported charging behavior. No procedure is approved or implemented here. Test on spare device first and preserve ability to restore stock firmware.
